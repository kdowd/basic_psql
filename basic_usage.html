Databases, the easy way

A database is a box that remembers things for you. In five short steps you will make a box, put a list of friends in it, and read the list back.

The whole idea first

Picture a box of cards on a shelf.

  • The box is a database.
  • The card inside it is a table.
  • One line on the card is a row — and each line is one friend.
  • Each space on that line is a column — one thing you know about the friend.

That is all a database is. Big ones just have more boxes and more cards.

Now do it

1

Open the program

psql -U postgres

You should see a new line that starts with postgres=#

The # means the computer is ready for you. You are not done. You need to choose a database and connect to it. Or, create a new database and connect. We will do the latter.

2

Make a new box

Call the box toybox. Type this and press Enter:

CREATE DATABASE toybox;

You should see CREATE DATABASE.

The ; at the end matters. If you leave it off, nothing happens at all.

3

Go inside the box

\c toybox

You should see You are now connected to database "toybox". Your line now starts with toybox=#.

A line starting with a backslash is a helper command, not a question. No ; needed for those.

4

Put a card in the box

The card is called friends. It has two spaces on it: name and age.

CREATE TABLE friends (name text, age integer);

You should see CREATE TABLE.

text means words. integer means a whole number. You have to say which one each space holds, so the computer knows what to keep there.

5

Write three friends on the card

INSERT INTO friends (name, age) VALUES ('Ann', 5), ('Ben', 6), ('Cara', 7);

You should see INSERT 0 3.

The 3 at the end means three friends went in. Names need quote marks around them. Numbers do not.

6

Look at the card

SELECT * FROM friends;

You should see this:

 name | age
------+-----
 Ann  |   5
 Ben  |   6
 Cara |   7
(3 rows)

There are your three friends, and (3 rows) tells you how many came back. You just made a real database and read it.

Now you try one

Add a fourth friend — use your own name if you like.

INSERT INTO friends (name, age) VALUES ('Dana', 8);

Then look at the card again, the same way as step 6:

SELECT * FROM friends;

You should see four friends now and (4 rows) at the bottom. Ann, Ben, Cara, and the one you just added.

If you get stuck

  • Nothing happened when you pressed Enter. You forgot the ; at the end. Type ; and press Enter again.
  • It says already exists. You already did that step. Just go on to the next one.
  • It says syntax error. Something small is spelled differently. Copy the line again and try once more.

Four words, and you are done

Word What it means
database The box.
table The card inside the box.
row One friend — one line on the card.
column One thing you know about a friend — name, or age.

You did it. You made a box called toybox, put a card called friends inside it, wrote three friends on the card, and read them back.

To come out, type \q and press Enter.
